Wave-21 recon found the vhc shell had been caching ./design-tokens.css — a file that lives one level up. cache.addAll rejects on any 404, so the entire 59-URL vhc shell never installed: every board's offline guarantee was silently absent, while every online demo stayed green. And ten registered payloads — including the data behind four cached boards — were in no shell at all, so those boards would render "loading…" forever offline. This wave fixes both and adds the shell gate (shellproof@1.0.0, ADR-0082): every shell entry must resolve, every payload and board must be cached or stated-excluded.
